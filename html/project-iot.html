IoT 온도 모니터링 시스템

STACK=C, MySQL, Python(Flask), Chart.js
ROLE=백엔드/DB 설계, 데이터 시각화
PERIOD=2026.05 ~ (기간 채우기)
REPO=github.com/yourid/iot-temp-monitoring

개요

C로 구현한 가상/시뮬레이션 센서에서 온도 데이터를 생성하고, 이를 MySQL에 저장한 뒤 Flask 백엔드를 통해 API로 제공, Chart.js로 웹 대시보드에서 실시간 시각화하는 프로젝트입니다.

DB 설계

(여기에 ERD 이미지 또는 테이블 스키마 설명 삽입)

  • sensor_readings(id, device_id, temperature, humidity, recorded_at)
  • devices(id, name, location)

구현 포인트

  • C 프로그램에서 시뮬레이션 데이터 생성 및 주기적 전송
  • Flask REST API 설계 (조회/필터링 엔드포인트)
  • Chart.js를 이용한 실시간 그래프 렌더링
