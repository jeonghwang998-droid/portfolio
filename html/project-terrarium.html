개요

ESP32와 DHT22/SHT31 센서로 테라리움 내부 온습도를 측정하고, 릴레이 모듈로 히터·가습기 등을 자동 제어합니다. 웹 대시보드에서 실시간 상태 확인 및 원격 제어가 가능합니다.

DB 설계

(여기에 ERD 이미지 또는 테이블 스키마 설명 삽입)

  • terrarium_readings(id, device_id, temperature, humidity, recorded_at)
  • devices(id, name, species, target_temp_min, target_temp_max)
  • control_logs(id, device_id, action, triggered_at)

구현 포인트

  • ESP32에서 센서 값 주기적 수집 및 전송
  • 임계값 기반 자동 제어 로직 (릴레이 ON/OFF)
  • 웹 대시보드로 실시간 모니터링 및 수동 제어
